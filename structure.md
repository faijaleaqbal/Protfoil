# App Flow & Architecture

## Tech stack
- Frontend: HTML, CSS, JavaScript (or React if the framework supports it well — choose the simplest option that renders cleanly as a static site)
- No backend required (static portfolio site)
- Hosting target: static hosting (e.g. GitHub Pages)

## Folder structure
/portfolio
  /index.html (or /src for React)
  /assets (images, icons)
  /styles
  /scripts (or /components if React)
  README.md

## Page flow
Single-page site with sections: Hero -> About -> Skills -> Projects -> Contact -> Footer
