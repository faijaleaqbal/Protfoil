# Portfolio Website — PRD

## What to build
A personal portfolio website for Md Faijal Eaqbal, a BCA student at Malda College (under Gour Banga University).

## Target users
Recruiters, potential clients/collaborators, and college peers viewing the portfolio online.

## Core features
- Hero/About section (name, education, short intro)
- Projects section showcasing GitHub repos: Pixel-Assistor, malda-portal, malda-college-notification-bot, Crypto_adss_bot
- Skills section
- Contact section (with links to GitHub: https://github.com/faijaleaqbal, and other socials if provided)
- Responsive design (mobile + desktop)
- Fast-loading, clean, modern UI
- Hero section with animated intro / typing effect for role/title
- About section (education, short bio, profile photo placeholder)
- Education timeline (Malda College — BCA, under Gour Banga University)
- Skills section with categorized skill bars/icons (languages, frameworks, tools)
- Projects section — cards for GitHub repos (Pixel-Assistor, malda-portal, malda-college-notification-bot, Crypto_adss_bot) with live-demo/GitHub links
- Achievements/Certifications section (placeholder cards, editable later)
- Resume section with downloadable PDF button (placeholder resume file for now)
- Testimonials/Recommendations section (placeholder, optional to fill later)
- Blog/Articles section (optional — just a "Coming soon" card if no posts yet)
- Contact section: contact form (name/email/message) + direct GitHub link (https://github.com/faijaleaqbal) + email + social icons
- Dark mode / light mode toggle
- Smooth scroll navigation + sticky navbar with active-section highlighting
- Scroll animations (fade-in/slide-in on sections)
- Footer with copyright + quick links
- SEO basics: meta title, meta description, favicon
- 404 page (if hosted with routing)
